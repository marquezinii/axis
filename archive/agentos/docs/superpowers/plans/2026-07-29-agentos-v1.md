# AgentOS v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a working AgentOS v1 desktop app — Electron UI talking to a standalone Fastify backend that runs one real AI provider (Claude, via the Claude Agent SDK) behind a provider-agnostic core, with SQLite persistence, a file-change diff viewer, a private GitHub repo, and an auto-updating desktop shortcut with the official icon.

**Architecture:** Electron renderer (React, sandboxed) talks over authenticated WebSocket/HTTP to a standalone Node/Fastify backend on `127.0.0.1:<dynamic port>`. The backend's core (Session Manager, Provider Router, Event Bus, Tool Manager) only knows a generic `ProviderAdapter` interface; `ClaudeProviderAdapter` (wrapping `@anthropic-ai/claude-agent-sdk`) is the only adapter wired up. Persistence goes through a `StorageProvider` interface (`packages/shared`), so the concrete storage engine is swappable; `SqliteStorageProvider` (backend-only, built on Node's built-in `node:sqlite`) is the only implementation in v1, storing projects/sessions/messages/file_changes with migrations and WAL.

**Tech Stack:** TypeScript everywhere, Electron 43.x (bundles Node ~24.x — required for `node:sqlite`; see Task 9/13's revision history), React 18, Fastify 4, `@anthropic-ai/claude-agent-sdk`, `node:sqlite` (Node's built-in SQLite module — no native compiled dependency), Vitest, Playwright, npm workspaces.

## Global Constraints

- Backend listens on `127.0.0.1` only, dynamic port, per-launch session token required on both HTTP and WS (spec §1).
- Electron: `nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`, minimal typed preload, no credentials reachable from renderer (spec §1).
- Persistence goes through a `StorageProvider` interface, not a concrete database type, anywhere outside `apps/backend/src/db/`. `SqliteStorageProvider` (wrapping `node:sqlite`'s `DatabaseSync`) is the only implementation in v1, so the storage engine can be swapped later (Postgres, remote storage, a different embedded SQLite) without touching Session Manager, Project Manager, or routes. Migrations, WAL mode, foreign keys enabled, `busy_timeout` set, schema versioning via `schema_migrations` table (spec §2, refined 2026-07-29 after a Node v24 native-build blocker on `better-sqlite3`).
- `node:sqlite` is backend-only — never imported from `apps/desktop/src/renderer` or `apps/desktop/src/preload` (those only ever talk to the backend over HTTP/WS).
- `DatabaseSync` is synchronous: keep individual queries small and fast. If a future task needs a heavy/long-running query, it must run in a worker thread or a separate process, not block the Fastify event loop — no such query exists in v1, so no worker-thread code is written now, but new persistence code must not introduce one either.
- All multi-statement writes use an explicit transaction (`BEGIN`/`COMMIT`/`ROLLBACK` via the `StorageProvider`), never bare sequential statements.
- Before applying a migration whose SQL contains `DROP`, `ALTER`, or `DELETE` (i.e. anything beyond additive `CREATE TABLE IF NOT EXISTS`/`CREATE INDEX IF NOT EXISTS`), the migration runner copies the existing database file to `<dbfile>.bak-<version>` first. v1's only migration (`001_init.sql`) is purely additive, so no backup fires in v1, but the runner must implement this check generically so later additive-vs-destructive migrations are covered automatically.
- Writes to the database are coordinated through a single `StorageProvider` instance per process (the backend creates exactly one, in `server.ts`, and passes it down) — never open a second independent connection to the same file within the backend process.
- The desktop app must not depend on a Node.js runtime the user happens to have installed. The backend process is launched via Electron's bundled runtime (Electron main spawns it with `ELECTRON_RUN_AS_NODE=1`, using `process.execPath`, i.e. Electron's own binary acting as Node — no assumption about a system-wide `node` binary or its version). This is implemented in Task 9. Electron is pinned to **43.2.0** specifically because it's the first stable line confirmed to bundle a Node version (~24.x) with `node:sqlite` support — Electron 31 (Node 20.18) does not have `node:sqlite` and crashes the backend at launch with `ERR_UNKNOWN_BUILTIN_MODULE`. Do not downgrade Electron below the version where `node:sqlite` is available without first re-verifying `process.versions.node` inside an `ELECTRON_RUN_AS_NODE`-spawned process.
- No automatic silent retries on provider errors in v1 — errors are surfaced to the user with a manual "try again" (spec §4).
- `TOOL_ERROR` must not kill the session; the turn continues (spec §4).
- Provider error categories are exactly: `AUTH_EXPIRED`, `RATE_LIMITED`, `QUOTA_EXCEEDED`, `PROVIDER_UNAVAILABLE`, `TOOL_ERROR`, `CONTEXT_EXCEEDED`, `CANCELLED`, `UNKNOWN` (spec §4).
- Official icon source: `C:\Users\felip\Downloads\AgentOS_icone_sem_fundo_CORRIGIDO_recortado.png` — used for app icon, window icon, installer icon, and desktop shortcut (spec §6).
- Desktop shortcut must be regenerated automatically on every build via a `postbuild` script (spec §6).
- Private GitHub repo `AgentOS` on account `marquezinii` (spec §6).

```typescript
export const PROVIDER_ERROR_CODES = [
  "AUTH_EXPIRED",
  "RATE_LIMITED",
  "QUOTA_EXCEEDED",
  "PROVIDER_UNAVAILABLE",
  "TOOL_ERROR",
  "CONTEXT_EXCEEDED",
  "CANCELLED",
  "UNKNOWN",
] as const;

export type ProviderErrorCode = (typeof PROVIDER_ERROR_CODES)[number];

export class ProviderError extends Error {
  constructor(
    public readonly code: ProviderErrorCode,
    message: string,
    public readonly cause?: unknown
  ) {
    super(message);
    this.name = "ProviderError";
  }
}

export interface ProviderCapabilities {
  streaming: boolean;
  fileEdit: boolean;
  terminal: boolean;
  git: boolean;
}

export interface ProviderModel {
  id: string;
  displayName: string;
}

export interface StartSessionOptions {
  projectPath: string;
  sessionId: string;
}

export interface SendMessageOptions {
  sessionId: string;
  text: string;
```

```typescript
// packages/shared/src/storage-provider.ts

export interface RunResult {
  changes: number;
  lastInsertRowid: number | bigint;
}

export interface PreparedStatement {
  run(...params: unknown[]): RunResult;
  get(...params: unknown[]): Record<string, unknown> | undefined;
  all(...params: unknown[]): Record<string, unknown>[];
}

/**
 * The only way any code outside `apps/backend/src/db/` touches persistence.
 * `SqliteStorageProvider` (apps/backend, built on node:sqlite) is the only
 * implementation in v1 — swapping storage engines later means writing a new
 * implementation of this interface, not touching Session Manager, Project
 * Manager, or routes.
 */
export interface StorageProvider {
  prepare(sql: string): PreparedStatement;
  exec(sql: string): void;
  /**
   * Runs `fn` inside BEGIN/COMMIT, rolling back on throw. Returns a function
   * with the same signature as `fn` that performs this wrapping when called.
   */
  transaction<T extends (...args: any[]) => any>(fn: T): T;
  close(): void;
}
```

```typescript
// apps/backend/src/db/sqlite-storage-provider.ts
import { DatabaseSync } from "node:sqlite";
import type {
  PreparedStatement,
  RunResult,
  StorageProvider,
} from "@agentos/shared";

class SqlitePreparedStatement implements PreparedStatement {
  constructor(private statement: ReturnType<DatabaseSync["prepare"]>) {}

  run(...params: unknown[]): RunResult {
    const result = this.statement.run(...(params as never[]));
    return {
      changes: Number(result.changes),
      lastInsertRowid: result.lastInsertRowid,
    };
  }

  get(...params: unknown[]): Record<string, unknown> | undefined {
    return this.statement.get(...(params as never[])) as
      | Record<string, unknown>
      | undefined;
  }

  all(...params: unknown[]): Record<string, unknown>[] {
    return this.statement.all(...(params as never[])) as Record<
      string,
      unknown
    >[];
  }
}

/**
 * Only place in the codebase allowed to import `node:sqlite`. Everything
 * else depends on `StorageProvider` from `@agentos/shared`.
 */
export class SqliteStorageProvider implements StorageProvider {
  private db: DatabaseSync;

  constructor(dbPath: string) {
    this.db = new DatabaseSync(dbPath);
    this.db.exec("PRAGMA journal_mode = WAL");
    this.db.exec("PRAGMA foreign_keys = ON");
    this.db.exec("PRAGMA busy_timeout = 5000");
  }

  prepare(sql: string): PreparedStatement {
    return new SqlitePreparedStatement(this.db.prepare(sql));
  }

  exec(sql: string): void {
    this.db.exec(sql);
  }

  transaction<T extends (...args: any[]) => any>(fn: T): T {
    const wrapped = (...args: Parameters<T>): ReturnType<T> => {
      this.db.exec("BEGIN");
      try {
        const result = fn(...args);
        this.db.exec("COMMIT");
        return result;
      } catch (err) {
        this.db.exec("ROLLBACK");
        throw err;
      }
    };
    return wrapped as T;
  }

  close(): void {
    this.db.close();
  }
}
```

```typescript
// apps/backend/src/db/migrate.ts
import type { StorageProvider } from "@agentos/shared";
import fs from "node:fs";
import path from "node:path";

interface Migration {
  version: number;
  file: string;
}

const MIGRATIONS: Migration[] = [{ version: 1, file: "001_init.sql" }];

// Matches genuine destructive DDL/DML statements only — a plain substring
// check on "DELETE" would also match "ON DELETE CASCADE"/"ON DELETE SET
// NULL" foreign-key clauses (e.g. in 001_init.sql), misflagging a purely
// additive migration as destructive.
const DESTRUCTIVE_STATEMENT_PATTERN =
  /\bDROP\s+TABLE\b|\bALTER\s+TABLE\b|\bDELETE\s+FROM\b/i;

function isDestructive(sql: string): boolean {
  return DESTRUCTIVE_STATEMENT_PATTERN.test(sql);
}

function backupDatabaseFile(dbPath: string, version: number): void {
  if (!fs.existsSync(dbPath)) return; // nothing to back up yet (fresh DB)
  const backupPath = `${dbPath}.bak-${version}`;
  fs.copyFileSync(dbPath, backupPath);
}

export function runMigrations(
  storage: StorageProvider,
  dbPath: string
): void {
  storage.exec(
    `CREATE TABLE IF NOT EXISTS schema_migrations (
       version INTEGER PRIMARY KEY,
       applied_at TEXT NOT NULL
     )`
  );

  const appliedRow = storage
    .prepare("SELECT MAX(version) as v FROM schema_migrations")
    .get() as { v: number | null };
  const applied = appliedRow.v ?? 0;

  const pending = MIGRATIONS.filter((m) => m.version > applied).sort(
    (a, b) => a.version - b.version
  );

  const insertVersion = storage.prepare(
    "INSERT INTO schema_migrations (version, applied_at) VALUES (?, ?)"
  );

  for (const migration of pending) {
    const sql = fs.readFileSync(
      path.join(__dirname, "migrations", migration.file),
      "utf-8"
    );

    if (isDestructive(sql)) {
      backupDatabaseFile(dbPath, migration.version);
    }

    const applyMigration = storage.transaction(() => {
      storage.exec(sql);
      insertVersion.run(migration.version, new Date().toISOString());
    });
    applyMigration();
  }
}
```

```typescript
// apps/backend/src/core/event-bus.ts
import type { AgentEvent } from "@agentos/shared";

type Handler = (event: AgentEvent) => void;

export class EventBus {
  private subscribers = new Map<string, Set<Handler>>();

  subscribe(sessionId: string, handler: Handler): () => void {
    if (!this.subscribers.has(sessionId)) {
      this.subscribers.set(sessionId, new Set());
    }
    this.subscribers.get(sessionId)!.add(handler);
    return () => {
      this.subscribers.get(sessionId)?.delete(handler);
    };
  }

  publish(event: AgentEvent): void {
    const handlers = this.subscribers.get(event.sessionId);
    if (!handlers) return;
    for (const handler of handlers) handler(event);
  }
}
```

```typescript
// apps/backend/src/core/session-manager.ts
import { randomUUID } from "node:crypto";
import type {
  AgentEvent,
  ProviderAdapter,
  SessionDTO,
  SessionStatus,
  StorageProvider,
} from "@agentos/shared";
import { ProviderError } from "@agentos/shared";
import type { EventBus } from "./event-bus";

interface SessionRow {
  id: string;
  project_id: string;
  provider_id: string;
  model: string | null;
  status: SessionStatus;
  created_at: string;
  updated_at: string;
}

function rowToDto(row: SessionRow): SessionDTO {
  return {
    id: row.id,
    projectId: row.project_id,
    providerId: row.provider_id,
    model: row.model,
    status: row.status,
    createdAt: row.created_at,
    updatedAt: row.updated_at,
  };
}

export class SessionManager {
  constructor(
    private db: StorageProvider,
    private bus: EventBus,
    private adapter: ProviderAdapter
  ) {}

  createSession(projectId: string, providerId: string): SessionDTO {
    const id = randomUUID();
    const now = new Date().toISOString();
    this.db
      .prepare(
        `INSERT INTO sessions (id, project_id, provider_id, model, status, created_at, updated_at)
         VALUES (?, ?, ?, NULL, 'created', ?, ?)`
      )
      .run(id, projectId, providerId, now, now);
    return this.getSession(id);
  }

  getSession(id: string): SessionDTO {
    const row = this.db
      .prepare("SELECT * FROM sessions WHERE id = ?")
      .get(id) as SessionRow | undefined;
    if (!row) throw new Error(`Session not found: ${id}`);
    return rowToDto(row);
  }

  private setStatus(id: string, status: SessionStatus): void {
    this.db
      .prepare("UPDATE sessions SET status = ?, updated_at = ? WHERE id = ?")
      .run(status, new Date().toISOString(), id);
  }

  private insertMessage(
    sessionId: string,
    role: "user" | "assistant",
    content: string
  ): void {
    this.db
      .prepare(
        `INSERT INTO messages (id, session_id, role, content, tool_events_json, created_at)
         VALUES (?, ?, ?, ?, '[]', ?)`
      )
      .run(randomUUID(), sessionId, role, content, new Date().toISOString());
  }

  private insertFileChange(event: {
    sessionId: string;
    path: string;
    changeType: "created" | "modified" | "deleted";
    diff: string;
  }): void {
    this.db
      .prepare(
        `INSERT INTO file_changes (id, session_id, path, change_type, diff, created_at)
         VALUES (?, ?, ?, ?, ?, ?)`
      )
      .run(
        randomUUID(),
        event.sessionId,
        event.path,
        event.changeType,
        event.diff,
        new Date().toISOString()
      );
  }

  async sendMessage(sessionId: string, text: string): Promise<void> {
    this.insertMessage(sessionId, "user", text);
    this.setStatus(sessionId, "executing");

    let assistantText = "";

    try {
      for await (const event of this.adapter.sendMessage({ sessionId, text })) {
        this.bus.publish(event);
        this.handleEvent(event, (delta) => {
          assistantText += delta;
        });
      }
      if (assistantText.length > 0) {
        this.insertMessage(sessionId, "assistant", assistantText);
      }
      this.setStatus(sessionId, "completed");
    } catch (err) {
      const code = err instanceof ProviderError ? err.code : "UNKNOWN";
      const message = err instanceof Error ? err.message : String(err);
      const status: SessionStatus = code === "CANCELLED" ? "interrupted" : "failed";
      this.setStatus(sessionId, status);
      this.bus.publish({
        type: "session_error",
        sessionId,
        code,
        message,
      });
    }
  }

  private handleEvent(event: AgentEvent, onTextDelta: (text: string) => void): void {
    switch (event.type) {
      case "text_delta":
        onTextDelta(event.text);
        break;
      case "file_changed":
        this.insertFileChange({
          sessionId: event.sessionId,
          path: event.path,
          changeType: event.changeType,
          diff: event.diff,
        });
        break;
      default:
        break;
    }
  }
}
```

```typescript
// apps/backend/src/providers/claude-provider-adapter.ts
import { query } from "@anthropic-ai/claude-agent-sdk";
import type {
  AgentEvent,
  ProviderAdapter,
  ProviderCapabilities,
  ProviderModel,
  SendMessageOptions,
  StartSessionOptions,
} from "@agentos/shared";
import { ProviderError } from "@agentos/shared";

export class ClaudeProviderAdapter implements ProviderAdapter {
  readonly providerId = "claude";

  getCapabilities(): ProviderCapabilities {
    return { streaming: true, fileEdit: true, terminal: true, git: true };
  }

  async listModels(): Promise<ProviderModel[]> {
    return [
      { id: "claude-sonnet-5", displayName: "Claude Sonnet 5" },
      { id: "claude-opus-5", displayName: "Claude Opus 5" },
    ];
  }

  async startSession(_options: StartSessionOptions): Promise<void> {
    // The Claude Agent SDK is stateless per-call in v1: each sendMessage()
    // call carries its own session context via the SDK's session resumption
    // options. No persistent handle to open here.
  }

  async *sendMessage(options: SendMessageOptions): AsyncIterable<AgentEvent> {
    const { sessionId, text } = options;

    try {
      for await (const sdkEvent of query({ prompt: text }) as AsyncIterable<any>) {
        const mapped = this.mapSdkEvent(sessionId, sdkEvent);
        if (mapped) yield mapped;
      }
      yield { type: "session_completed", sessionId };
    } catch (err) {
      throw this.normalizeError(err);
    }
  }

  async cancel(_sessionId: string): Promise<void> {
    // v1: cancellation is cooperative via AbortController wiring in Task 6;
    // the adapter itself has no persistent handle to cancel directly.
  }

  private mapSdkEvent(sessionId: string, sdkEvent: any): AgentEvent | null {
    switch (sdkEvent.type) {
      case "assistant": {
        const textPart = sdkEvent.message?.content?.find(
          (c: any) => c.type === "text"
        );
        if (!textPart) return null;
        return { type: "text_delta", sessionId, text: textPart.text };
      }
      case "tool_use":
        return {
          type: "tool_call_started",
          sessionId,
          toolName: sdkEvent.name,
          toolCallId: sdkEvent.id,
        };
      case "tool_result":
        return {
          type: "tool_call_finished",
          sessionId,
          toolCallId: sdkEvent.tool_use_id,
          success: !sdkEvent.is_error,
        };
      default:
        return null;
    }
  }

  private normalizeError(err: unknown): ProviderError {
    if (err instanceof ProviderError) return err;
    const message = err instanceof Error ? err.message : String(err);
    const lower = message.toLowerCase();

    if (lower.includes("auth") || lower.includes("unauthorized")) {
      return new ProviderError("AUTH_EXPIRED", message, err);
    }
    if (lower.includes("rate limit")) {
      return new ProviderError("RATE_LIMITED", message, err);
    }
    if (lower.includes("quota") || lower.includes("credit")) {
      return new ProviderError("QUOTA_EXCEEDED", message, err);
    }
    if (lower.includes("context") && lower.includes("exceed")) {
      return new ProviderError("CONTEXT_EXCEEDED", message, err);
    }
    if (lower.includes("cancel") || lower.includes("abort")) {
      return new ProviderError("CANCELLED", message, err);
    }
    if (lower.includes("timeout") || lower.includes("unavailable")) {
      return new ProviderError("PROVIDER_UNAVAILABLE", message, err);
    }
    return new ProviderError("UNKNOWN", message, err);
  }
}
```

```typescript
// apps/backend/src/core/project-manager.ts
import { randomUUID } from "node:crypto";
import path from "node:path";
import { execSync } from "node:child_process";
import type { ProjectDTO, StorageProvider } from "@agentos/shared";

interface ProjectRow {
  id: string;
  name: string;
  path: string;
  git_remote: string | null;
  default_branch: string | null;
  created_at: string;
}

function rowToDto(row: ProjectRow): ProjectDTO {
  return {
    id: row.id,
    name: row.name,
    path: row.path,
    gitRemote: row.git_remote,
    defaultBranch: row.default_branch,
    createdAt: row.created_at,
  };
}

export class ProjectManager {
  constructor(private db: StorageProvider) {}

  registerProject(folderPath: string): ProjectDTO {
    const normalizedPath = path.resolve(folderPath);
    const existing = this.db
      .prepare("SELECT * FROM projects WHERE path = ?")
      .get(normalizedPath) as ProjectRow | undefined;
    if (existing) return rowToDto(existing);

    const { gitRemote, defaultBranch } = this.detectGit(normalizedPath);
    const id = randomUUID();
    const now = new Date().toISOString();

    this.db
      .prepare(
        `INSERT INTO projects (id, name, path, git_remote, default_branch, created_at, settings_json)
         VALUES (?, ?, ?, ?, ?, ?, '{}')`
      )
      .run(
        id,
        path.basename(normalizedPath),
        normalizedPath,
        gitRemote,
        defaultBranch,
        now
      );

    return {
      id,
      name: path.basename(normalizedPath),
      path: normalizedPath,
      gitRemote,
      defaultBranch,
      createdAt: now,
    };
  }

  listProjects(): ProjectDTO[] {
    const rows = this.db
      .prepare("SELECT * FROM projects ORDER BY created_at DESC")
      .all() as ProjectRow[];
    return rows.map(rowToDto);
  }

  private detectGit(folderPath: string): {
    gitRemote: string | null;
    defaultBranch: string | null;
  } {
    try {
      // symbolic-ref (not rev-parse --abbrev-ref) so this also works on a
      // freshly `git init`'d repo with no commits yet, where HEAD is
      // ambiguous to rev-parse.
      const branch = execSync("git symbolic-ref --short HEAD", {
        cwd: folderPath,
        stdio: ["ignore", "pipe", "ignore"],
      })
        .toString()
        .trim();
      let remote: string | null = null;
      try {
        remote = execSync("git remote get-url origin", {
          cwd: folderPath,
          stdio: ["ignore", "pipe", "ignore"],
        })
          .toString()
          .trim();
      } catch {
        remote = null;
      }
      return { gitRemote: remote, defaultBranch: branch || null };
    } catch {
      return { gitRemote: null, defaultBranch: null };
    }
  }
}
```

```typescript
// apps/backend/src/server.ts
import Fastify, { type FastifyInstance } from "fastify";
import websocketPlugin from "@fastify/websocket";
import { openDatabase } from "./db/connection";
import { runMigrations } from "./db/migrate";
import { EventBus } from "./core/event-bus";
import { SessionManager } from "./core/session-manager";
import { ProjectManager } from "./core/project-manager";
import { ClaudeProviderAdapter } from "./providers/claude-provider-adapter";
import { registerProjectRoutes } from "./routes/projects";
import { registerSessionRoutes } from "./routes/sessions";

export interface BuildServerOptions {
  dbPath: string;
  sessionToken: string;
}

const PUBLIC_ROUTES = new Set(["/health"]);

export async function buildServer(
  options: BuildServerOptions
): Promise<FastifyInstance> {
  const db = openDatabase(options.dbPath);
  runMigrations(db, options.dbPath);

  db.prepare(
    "INSERT OR IGNORE INTO providers (id, name, kind, capabilities_json, enabled) VALUES (?, ?, ?, ?, 1)"
  ).run("claude", "Claude", "cli", JSON.stringify({
    streaming: true,
    fileEdit: true,
    terminal: true,
    git: true,
  }));

  const bus = new EventBus();
  const adapter = new ClaudeProviderAdapter();
  const sessionManager = new SessionManager(db, bus, adapter);
  const projectManager = new ProjectManager(db);

  const app = Fastify();
  await app.register(websocketPlugin);

  app.addHook("onRequest", async (request, reply) => {
    if (PUBLIC_ROUTES.has(request.url)) return;
    const header = request.headers.authorization;
    const token = header?.startsWith("Bearer ") ? header.slice(7) : null;
    if (token !== options.sessionToken) {
      reply.code(401).send({ error: "unauthorized" });
    }
  });

  app.get("/health", async () => ({ status: "ok" }));

  registerProjectRoutes(app, projectManager);
  registerSessionRoutes(app, sessionManager, db);

  app.get<{ Params: { id: string } }>(
    "/ws/sessions/:id",
    { websocket: true },
    (connection, request) => {
      const token = (request.query as { token?: string }).token;
      if (token !== options.sessionToken) {
        connection.socket.close(4001, "unauthorized");
        return;
      }
      const sessionId = request.params.id;
      const unsubscribe = bus.subscribe(sessionId, (event) => {
        connection.socket.send(JSON.stringify(event));
      });
      connection.socket.on("close", unsubscribe);
      connection.socket.on(
        "message",
        (raw: Buffer) => {
          const parsed = JSON.parse(raw.toString());
          if (parsed.type === "send_message") {
            sessionManager.sendMessage(sessionId, parsed.text);
          }
        }
      );
    }
  );

  return app;
}
```

```typescript
// apps/desktop/src/main/backend-supervisor.ts
import type { ChildProcess } from "node:child_process";
import { spawn as defaultSpawn } from "node:child_process";

export interface BackendReadyInfo {
  port: number;
  sessionToken: string;
}

export interface BackendSupervisorOptions {
  command: string;
  args: string[];
  env?: NodeJS.ProcessEnv;
  spawnFn?: typeof defaultSpawn;
}

type CrashHandler = (exitCode: number | null) => void;

export class BackendSupervisor {
  private spawnFn: typeof defaultSpawn;
  private child: ChildProcess | null = null;
  private crashHandlers: CrashHandler[] = [];
  private expectedShutdown = false;

  constructor(private options: BackendSupervisorOptions) {
    this.spawnFn = options.spawnFn ?? defaultSpawn;
  }

  onCrash(handler: CrashHandler): void {
    this.crashHandlers.push(handler);
  }

  start(): Promise<BackendReadyInfo> {
    this.expectedShutdown = false;
    const child = this.spawnFn(this.options.command, this.options.args, {
      env: this.options.env
        ? { ...process.env, ...this.options.env }
        : process.env,
    });
    this.child = child;

    return new Promise((resolve, reject) => {
      let buffer = "";
      const onData = (chunk: Buffer) => {
        buffer += chunk.toString();
        const newlineIndex = buffer.indexOf("\n");
        if (newlineIndex === -1) return;
        const line = buffer.slice(0, newlineIndex);
        buffer = buffer.slice(newlineIndex + 1);
        try {
          const parsed = JSON.parse(line);
          if (parsed.type === "ready") {
            child.stdout?.off("data", onData);
            resolve({ port: parsed.port, sessionToken: parsed.sessionToken });
          }
        } catch {
          // ignore non-JSON stdout noise
        }
      };
      child.stdout?.on("data", onData);

      child.on("exit", (code) => {
        if (!this.expectedShutdown) {
          for (const handler of this.crashHandlers) handler(code);
        }
      });

      child.on("error", (err) => reject(err));
    });
  }

  async stop(): Promise<void> {
    if (!this.child) return;
    this.expectedShutdown = true;
    this.child.kill();
    this.child = null;
  }
}
```

```typescript
// apps/desktop/src/renderer/agentos-client.ts
import type {
  AgentEvent,
  ProjectDTO,
  SessionDTO,
} from "@agentos/shared";

export interface ConnectionInfo {
  port: number;
  sessionToken: string;
}

export class AgentosClient {
  constructor(private connection: ConnectionInfo) {}

  private baseUrl(): string {
    return `http://127.0.0.1:${this.connection.port}`;
  }

  private async request<T>(pathName: string, init?: RequestInit): Promise<T> {
    const response = await fetch(`${this.baseUrl()}${pathName}`, {
      ...init,
      headers: {
        ...(init?.headers ?? {}),
        Authorization: `Bearer ${this.connection.sessionToken}`,
        ...(init?.body ? { "Content-Type": "application/json" } : {}),
      },
    });
    if (!response.ok) {
      throw new Error(`Request failed: ${pathName} (${response.status})`);
    }
    return response.json();
  }

  listProjects(): Promise<ProjectDTO[]> {
    return this.request("/projects");
  }

  registerProject(folderPath: string): Promise<ProjectDTO> {
    return this.request("/projects", {
      method: "POST",
      body: JSON.stringify({ path: folderPath }),
    });
  }

  createSession(projectId: string, providerId: string): Promise<SessionDTO> {
    return this.request("/sessions", {
      method: "POST",
      body: JSON.stringify({ projectId, providerId }),
    });
  }

  streamSession(
    sessionId: string,
    onEvent: (event: AgentEvent) => void
  ): () => void {
    const ws = new WebSocket(
      `ws://127.0.0.1:${this.connection.port}/ws/sessions/${sessionId}?token=${this.connection.sessionToken}`
    );
    ws.onmessage = (message) => {
      onEvent(JSON.parse(message.data as string));
    };
    return () => ws.close();
  }

  sendMessage(sessionId: string, text: string): void {
    const ws = new WebSocket(
      `ws://127.0.0.1:${this.connection.port}/ws/sessions/${sessionId}?token=${this.connection.sessionToken}`
    );
    ws.onopen = () => {
      ws.send(JSON.stringify({ type: "send_message", text }));
    };
  }
}
```

```tsx
// apps/desktop/src/renderer/App.tsx
import { useEffect, useState } from "react";
import type { ProjectDTO, SessionDTO, FileChangeDTO } from "@agentos/shared";
import { AgentosClient } from "./agentos-client";
import { ProjectList } from "./components/ProjectList";
import { ChatPanel, type ChatMessage } from "./components/ChatPanel";
import { DiffViewer } from "./components/DiffViewer";

declare global {
  interface Window {
    agentos: {
      getConnectionInfo: () => { port: number; sessionToken: string };
    };
  }
}

export function App() {
  const [client] = useState(() => new AgentosClient(window.agentos.getConnectionInfo()));
  const [projects, setProjects] = useState<ProjectDTO[]>([]);
  const [selectedProject, setSelectedProject] = useState<ProjectDTO | null>(null);
  const [session, setSession] = useState<SessionDTO | null>(null);
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [fileChanges, setFileChanges] = useState<FileChangeDTO[]>([]);

  useEffect(() => {
    client.listProjects().then(setProjects);
  }, [client]);

  const handleAddProject = async () => {
    const folderPath = window.prompt("Project folder path:");
    if (!folderPath) return;
    const project = await client.registerProject(folderPath);
    setProjects((prev) => [project, ...prev]);
  };

  const handleSelectProject = async (project: ProjectDTO) => {
    setSelectedProject(project);
    const newSession = await client.createSession(project.id, "claude");
    setSession(newSession);
    setMessages([]);
    setFileChanges([]);

    client.streamSession(newSession.id, (event) => {
      if (event.type === "text_delta") {
        setMessages((prev) => {
          const last = prev[prev.length - 1];
          if (last?.role === "assistant") {
            return [
              ...prev.slice(0, -1),
              { role: "assistant", text: last.text + event.text },
            ];
          }
          return [...prev, { role: "assistant", text: event.text }];
        });
      }
      if (event.type === "file_changed") {
        setFileChanges((prev) => [
          ...prev,
          {
            id: crypto.randomUUID(),
            sessionId: newSession.id,
            path: event.path,
            changeType: event.changeType,
            diff: event.diff,
            createdAt: new Date().toISOString(),
          },
        ]);
      }
    });
  };

  const handleSend = (text: string) => {
    if (!session) return;
    setMessages((prev) => [...prev, { role: "user", text }]);
    client.sendMessage(session.id, text);
  };

  return (
    <div style={{ display: "flex", height: "100vh" }}>
      <aside style={{ width: 260 }}>
        <ProjectList
          projects={projects}
          selectedProjectId={selectedProject?.id ?? null}
          onSelect={handleSelectProject}
          onAddProject={handleAddProject}
        />
      </aside>
      <main style={{ flex: 1 }}>
        <ChatPanel messages={messages} onSend={handleSend} />
      </main>
      <aside style={{ width: 320 }}>
        <DiffViewer fileChanges={fileChanges} />
      </aside>
    </div>
  );
}
```

```powershell
# scripts/update-desktop-shortcut.ps1
# Regenerates the AgentOS desktop shortcut to point at the latest build.
# Runs automatically after every `npm run build` via the root postbuild script.

$ErrorActionPreference = "Stop"

$repoRoot = Split-Path -Parent $PSScriptRoot
$releaseDir = Join-Path $repoRoot "apps\desktop\release"
$iconPath = Join-Path $repoRoot "assets\icon\icon.ico"

if (-not (Test-Path $releaseDir)) {
    Write-Host "No release build found at $releaseDir yet - skipping shortcut update."
    exit 0
}

$exe = Get-ChildItem -Path $releaseDir -Filter "AgentOS*.exe" -Recurse |
    Sort-Object LastWriteTime -Descending |
    Select-Object -First 1

if (-not $exe) {
    Write-Host "No AgentOS executable found under $releaseDir yet - skipping shortcut update."
    exit 0
}

$desktopPath = [Environment]::GetFolderPath("Desktop")
$shortcutPath = Join-Path $desktopPath "AgentOS.lnk"

$shell = New-Object -ComObject WScript.Shell
$shortcut = $shell.CreateShortcut($shortcutPath)
$shortcut.TargetPath = $exe.FullName
$shortcut.WorkingDirectory = $exe.DirectoryName
if (Test-Path $iconPath) {
    $shortcut.IconLocation = $iconPath
}
$shortcut.Save()

Write-Host "Updated desktop shortcut -> $($exe.FullName)"
```

- [ ] **Step 2: Add `electron-builder` config for the icon and output dir**

Add to `apps/desktop/package.json`, alongside the existing `scripts` block:

```json
  "build": {
    "appId": "com.agentos.desktop",
    "productName": "AgentOS",
    "directories": {
      "output": "release"
    },
    "win": {
      "icon": "../../assets/icon/icon.ico",
```

`signExecutable: false` skips electron-builder's `winCodeSign` tool download
and code signing — v1 ships unsigned, and that tool's archive fails to
extract on machines without symlink privilege (a Windows dev-mode/admin
setting), which isn't a reasonable thing to require just to run a local
build. **Not** `signAndEditExecutable: false`: that key skips ALL resource
editing on the `.exe`, including icon embedding, not just signing —
electron-builder's own build log warns about this and recommends
`signExecutable: false` specifically to keep the icon applied. Using the
wrong key was the actual cause of a real bug where the packaged app's icon
showed as Electron's generic default instead of the AgentOS icon.

Add `"dist": "electron-builder"` to the `scripts` block, and update the root
`build` script (Task 1) to run it:


## Task 14: Final integration pass and push

> **Revised 2026-07-29:** the real packaged-app manual smoke test (the step
> this task exists to do) surfaced three production bugs that only appear
> once the app is actually installed/packaged, not in dev mode — fixed as
> part of this task rather than deferred, since they made the app
> completely unusable for the end user:
>
> 1. **Backend crashed once packaged.** `apps/backend`'s plain `tsc` output
>    depends on `node_modules` resolution; electron-builder's
>    `extraResources` live outside `app.asar`, unreachable by Node's module
>    resolver, so the packaged backend died with `MODULE_NOT_FOUND`. Fixed
>    by bundling the backend with esbuild into a single self-contained ESM
>    file (`apps/backend/esbuild.config.js`, `dist/index.mjs`) that inlines
>    all dependencies, keeping only real Node builtins external. ESM (not
>    CJS) because the Claude Agent SDK relies on real `import.meta.url`
>    semantics; a banner restores `require()` via `createRequire` for the
>    handful of CJS deps (e.g. fastify's `avvio`) that still call it
>    dynamically. `apps/desktop/package.json` gained an `extraResources`
>    entry copying `../backend/dist` into `resources/backend/dist`, and
>    `main.ts` gained a `resolveBackendEntry()` helper picking
>    `process.resourcesPath` (packaged) vs. the dev-relative path via
>    `app.isPackaged`.
> 2. **The desktop shortcut launched the installer, not the app.**
>    `scripts/update-desktop-shortcut.ps1` globbed `AgentOS*.exe` under
>    `release/` and picked the most-recently-modified match — which is
>    always the NSIS installer (`AgentOS Setup *.exe`), since
>    electron-builder writes it after `win-unpacked/`. Running the
>    installer did a fresh reinstall and replaced the icon with a generic
>    one. Fixed by targeting `release/win-unpacked/AgentOS.exe` explicitly
>    (electron-builder's standard unpacked-app path for a non-portable NSIS
>    build), not a glob-by-mtime.
> 3. **A failed backend start hung the app forever with no error.**
>    `BackendSupervisor.start()`'s promise only resolved on the "ready"
>    stdout line or rejected on the child process's `"error"` event
>    (spawn-level failures only). If the backend process exited for any
>    other reason during startup, `"exit"` fired the `onCrash` handlers
>    (which just retry `start()`) but the *original* promise from the first
>    call was never settled — so `createWindow()`'s `await` hung
>    indefinitely with a spinning cursor and no visible error. Fixed:
>    `start()` now rejects immediately if the child exits before "ready"
>    fires, with the exit code in the error message. `main.ts` also now
>    catches `createWindow()`'s rejection and quits with a logged error
>    instead of leaving a silently-stuck process.
>
> Verified for real: `apps/desktop/release/win-unpacked/AgentOS.exe`
> launched directly (not `npm run dev`) opened a window with the rendered
> project-list/chat UI within ~10s, no hang; the regenerated Desktop
> shortcut's `TargetPath` was confirmed (via COM `WScript.Shell`) to point
> at `win-unpacked\AgentOS.exe` with `IconLocation` set to the official
> `.ico`, not the installer or a generic icon.
